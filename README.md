<h1>DUAL_MODE_RADIO-DMR </h1>
DMR(DUAL MODE RADIO) is a small portable radio that combines two different things in one device:<ul>
<li>AIRLINK is a small portable radio that combines two different things in one device:</li>
<li>VHF amateur radio for two-way communication</li></ul><br>
The controller is an ESP32. It controls the display, buttons, rotary encoder and the radio module<br>
<h3> Main Components</h3>

- ESP32 DevKitC – main controller
- SA828-VHF – VHF transceiver
- RDA5807M – FM receiver
- PAM8403 – audio amplifier
- OLED – displays frequency and status
- Rotary Encoder – tuning and navigation
- TP4056 – battery charging
- Boost Converter – provides 5V power
- 3.3V Regulator – provides 3.3V power
- 18650 – rechargeable battery
- SMA Connector – VHF antenna connection
- Speakers – audio output
